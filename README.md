# Peanut Butter & Jelly

A Jellyfin plugin that syncs tags from [Deezer](https://developers.deezer.com/) onto your music (genres, artists, dates, covers, explicit). Optional extras: lyrics (LRCLIB) and artist bios.

**Jellyfin 10.11.+** Runs as a scheduled task.

## Install

1. **Dashboard → Plugins → Repositories** → add:
   - Name: `Peanut Butter & Jelly`
   - URL: `https://cdn.jsdelivr.net/gh/TidBits16/peanut-butter-jelly@main/manifest.json`
2. **Catalog** → install → restart when asked.
3. Configure under **Plugins → Peanut Butter & Jelly**, or run from **Scheduled Tasks**.
